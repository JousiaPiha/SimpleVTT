# Usability improvements

Completed: portable sessions. Save Session As copies all indexed media and saved preparation into an empty folder; Open edits in place, Close returns to Default Session, and Clear Default Session starts a new draft. Includes autosave, a server folder browser, configurable starting location, and storage recovery. Player displays start blank after startup and session changes.

Completed: soundboard groups and icons. Sound tiles support named groups, search/filtering, a palette of 32 bundled Lucide icons, and custom images uploaded or selected from the media library. Settings persist in SQLite and remain GM-only.

Possible later additions: audio crossfades, favorite sounds, keyboard shortcuts, and scene duplication.
